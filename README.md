🛍️ Customer Behavior Analysis

Using Python, SQL & Power BI

📌 Project Overview

This project focuses on analyzing customer shopping behavior to uncover patterns, trends, and actionable business insights.
By combining Python for data analysis, SQL for querying, and Power BI for visualization, the project demonstrates an end-to-end data analytics workflow.

The insights generated help businesses understand customer preferences, spending habits, and purchasing behavior, enabling better decision-making and strategy planning.

🎯 Objectives

Analyze customer purchasing patterns

Identify high-value customers and top products

Understand spending behavior across categories

Track customer trends over time

Create interactive dashboards for business insights

🛠️ Tools & Technologies

Python – Data cleaning, analysis & feature engineering

Pandas, NumPy, Matplotlib, Seaborn

SQL – Data extraction, joins, aggregations & KPIs

Power BI – Interactive dashboards & visual storytelling

Jupyter Notebook – Analysis and experimentation

Git & GitHub – Version control and project sharing
